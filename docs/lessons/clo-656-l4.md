# `cargo run` needs `--bin lok` in this package

The package declares three binaries (`lok` and `lokomotiv`, both on `src/main.rs`,
plus `silence_probe`), and there is no `default-run`. `cargo run -- run wf.toml`
fails with "could not determine which binary to run". The CLO-656 spec shipped a
manual recipe in that form, and a reviewer caught it only by running it.

Rule: write manual end-to-end recipes as `cargo run --bin lok -- run <workflow.toml>`,
and run every recipe once before it goes into a spec's evaluation table.

How to apply: when a spec includes a shell recipe, paste in its real output from a
local run as the "before" evidence, so a broken command shows up while the spec is
being written.
