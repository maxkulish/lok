# `cargo test --lib <module>` passes with zero tests for bin-only modules

`template`, `workflow` and most CLI modules are declared in `src/main.rs`, not in
`src/lib.rs`. `cargo test --lib template::tests` therefore filters everything out,
reports `0 passed` and exits 0. A spec or a revert check that uses `--lib` looks
green while proving nothing. An external reviewer caught this in CLO-655's
evaluation table before implementation.

Rule: focused test runs for these modules use `cargo test --bin lok <filter>`. A
focused run or revert check counts only if its summary shows a non-zero
`passed` count.

How to apply: check which crate declares the module (`rg '^mod ' src/main.rs
src/lib.rs`) before writing test commands into a spec.
