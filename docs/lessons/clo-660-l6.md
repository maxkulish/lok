# The three aggregation files drift independently after a Linear cancellation

The 2026-09-13 backlog review canceled CLO-610 and CLO-624 in Linear while the Lok
project was archived. The next sync (#108) removed them from `docs/PROJECT.md` only.
`docs/ROADMAP.md` still showed CLO-610 as Not started, and `docs/DEPENDENCIES.md` still
listed both as ready. The CLO-660 spec wrote its ROADMAP criterion from that stale row
and credited CLO-610 with protecting release archives. The error surfaced only while
merging main, after the pre-PR validation had passed.

Rule: before prose, a spec or an aggregation edit names another ticket's status or
role, read that ticket in Linear (`includeArchived` matters while Lok is archived). A
cancellation touches all three files: PROJECT Up Next, ROADMAP (status Canceled; keep
the row), and DEPENDENCIES Unblocked & Ready.

How to apply: when a sync removes a canceled ticket from one aggregation file, grep the
other two for its ID in the same change. As of b2e23f9, ROADMAP Phase 14 still lists
canceled CLO-624 as Not started.
