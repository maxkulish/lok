# Claim a bundled ticket when the bundling decision is made

CLO-655's spec bundled CLO-656 at 10:02 and was approved at 11:30. Nothing
recorded that claim outside the CLO-655 workflow file. CLO-656 stayed in
Backlog, so a parallel session started it independently at 12:16 and opened
PR #100 against the same functions. The overlap only showed up in Linear after
PR #101 was opened. By then both PRs were complete and could not both merge.

Rule: when a task absorbs another ticket, claim that ticket immediately. Move it
to In Progress and comment with the absorbing task and branch. Before starting
any task, check `git worktree list` and the open PRs for the ticket IDs involved.

How to apply: make the claim part of the spec phase's bundling decision, not
the PR phase.
